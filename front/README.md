# AdiJacinto – Site Corporativo

Site institucional com React + Vite + Tailwind CSS + React Router.

## Estrutura de Páginas

| Rota | Página |
|------|--------|
| `/` | Home (Hero, Serviços, CTA) |
| `/servicos` | Lista completa de serviços |
| `/sobre` | Sobre a empresa e equipa |
| `/orcamento` | Formulário de orçamento |
| `/contato` | Formulário de contacto |

## Instalação

```bash
npm install
npm run dev
